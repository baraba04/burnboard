BURNBOARD - READ ME FIRST

Burnboard shows your Claude Code usage: tokens, cost at API prices, and your plan limits. Everything is calculated on your Mac.


INSTALL (about two minutes)

1. Drag "Burnboard" onto the "Applications" folder in this window.

2. Open Burnboard from the Applications folder. macOS will say it cannot verify the developer and will not open it. That is expected: this app is not signed with an Apple Developer ID. Click "Done".

3. Open System Settings, then "Privacy & Security". Scroll down to the "Security" section. You will see a message that "Burnboard" was blocked to protect your Mac. Click "Open Anyway" next to it.

4. Confirm with Touch ID or your Mac password. If macOS asks once more, click "Open Anyway" again.

5. From now on Burnboard opens normally with a double click. You only do steps 2 to 4 once.


WHAT IT NEEDS (the first screen of the app checks each of these and shows the fix)

- macOS 12 or later.

- Python 3 from Apple's command line tools. If it is missing, the app has a button that starts Apple's own installer.

- Claude Code, installed. If it is missing, the app has a button that opens the download page.

- Claude Code signed in, for the plan limits. If nobody is signed in, the app has a button: Claude Code opens Anthropic's own sign-in page in your browser and the window updates when you are done. Burnboard never sees your password or token. The dashboard works from the logs without it.

Whatever is missing, you fix with one click and then click "Check again".


WHAT IT DOES WITH YOUR DATA

It reads the Claude Code logs on this Mac and, for your main Claude folder, also ~/.config/claude and the Cowork sessions of the Claude desktop app when there are any. Whenever it opens it asks your own Claude Code for its version and whether you are signed in. Nothing from your logs is sent anywhere. These are the only network requests: during a refresh it downloads a public price list from raw.githubusercontent.com and works out the costs itself; once per refresh your own Claude Code makes one small call on your Claude subscription to read the plan limits (you can switch that off on the first screen; it may include your own Claude Code instruction files, as any Claude Code session does, but no log content or usage data); and when you click the sign-in button, Claude Code signs you in on Anthropic's own page. The full details, and how to remove everything, are in the README.md of the source.

To check that your copy of the .dmg is the one that was made, run "shasum -a 256" on it in Terminal and compare the result with the number in the Burnboard-<version>.dmg.sha256 file that came with it.
